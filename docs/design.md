# 프로그램 설계

## 자료 관리
- 상품명 : 문자열 배열로 선언하여 관리한다.
- 상품가격 : 정수형 배열로 선언하여 관리한다.
- 상품재고 : 정수형 배열로 선언하여 관리한다.
- 현재잔액/판매매출 : 정수형 변수로 선언하여 관리한다.
- 같은 인덱스 번호에 있는 상품명, 가격, 재고가 하나의 상품 정보가 되도록 관리한다.

## 프로그램 동작 순서
1. 상품목록, 현재 잔액, 메뉴를 출력한다.
2. 사용자한테 번호를 입력받는다. 
3. 입력 받은 번호에 따라서 현금 투입, 상품 구매하기, 등을 알맞게 실행한다.
4. 종료 메뉴를 선택하면 프로그램을 종료한다.

## 구매 처리
- 상품 번호가 if문으로 같은지 확인한다.
- 상품 재고가 있는지 if문으로 확인한다.
- 현재 잔액이 상품 가격 이상인지 if문으로 확인한다.
- 모든 조건이 맞으면 구매를 완료하고 잔액, 재고, 매출을 변경한다.
- 조건이 틀리면 안내 메시지를 출력한다.
