# 프로그램 설계

## 자료 관리
- `product_name`: 상품 이름을 문 자열 배열로 선언하여 관리한다.
- `product_price`: 상품 가격을 정수형 배열로 선언하여 관리한다.
- `product_stock`: 상품 재고를 정수형 배열로 선언하여 관리한다.
- `money`:현재잔액을 정수형 변수로 선언하여 관리한다.
- ``
- 같은 인덱스 번호에 있는 상품명, 가격, 재고가 하나의 상품 정보가 되도록 관리한다.

## 프로그램 동작 흐름
1. 잔액과 매출을 0으로 초기화 시킨다.
2. 반복문 안에서 자판기 메뉴를 출력한다.
3. 사용자한테 메뉴 번호를 입력받는다.
4. 조건문으로 입력받은 번호를 확인한다.
5. 번호에 따라 구매하기, 잔돈 반환하기, 프로그램 종료, 등을 실행한다.
6. 사용자가 물건을 구매하였으면 잔액과 재고 변수를 감소시킨다.
7. 잔돈을 반환하면 금액만큼 동전이나 지폐 갯수를 계산하여 출력하고 잔액을 0원으로 바꾼다.
8. 매출확인을 하면 
프로그램을 종료한다.

## 메뉴 처리
- `veding_input`라는 함수를 만들어서 처리한다.
- 메뉴에 있는 번호를 사용자에게 입력받는다.
- `if`문으로 입력 받은 번호와 지정해놓은 조건이 맞는지 확인한다.
- 조건이 맞으면 해당 번호의 기능을 실행한다.
- 조건이 틀리면 안내 메시지를 출력하고 다시 입력받는다.

## 구매 처리
- `veding_buy`라는 함수를 만들었다.
- 상품 번호가 if문으로 같은지 확인한다.
- 상품 재고가 있는지 if문으로 확인한다.
- 현재 잔액이 상품 가격 이상인지 if문으로 확인한다.
- 모든 조건이 맞으면 구매를 완료하고 잔액, 재고, 매출을 변경한다.
- 조건이 틀리면 안내 메시지를 출력하고 다시 입력받는다.
