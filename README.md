# C 자판기 프로그램

## 프로젝트 소개
C언어를 이용해 상품을 구매하고 잔액과 재고에 따라 품절 표시 및 판매 매출을 관리하는 자판기 프로그램을 만들 예정입니다.

## 주제 선정 이유
C언어에서 배운 조건문, 반복문, 배열과 함수 등을 활용하여 
실제로 판매하는 상품을 구매하고 잔돈까지 반환되는 기능이
동작하는 자판기 프로그램을 구현해보고 싶어 선택하였습니다.

## 프로그램 설계
메뉴를 반복해서 보여주고 사용자가 선택한 기능을 실행하는 방식으로 만들 예정입니다.
- 자세한 설계는 [`docs/design.md`](docs/design.md)에 정리하였습니다.

## 개발 환경
- 프로그래밍 언어 : C
- 개발 도구 : CLion

## 구현 기능
- 상품 목록과 가격 표시
- 돈 투입 및 잔액 표시
- 상품 구매
- 구매 후 재고 감소
- 재고가 없을 때 품절 안내
- 남은 잔액 반환
- 판매 매출 확인
- 판매 매출 초기화
- 자판기 다시 이용하기
- 프로그램 종료하기
